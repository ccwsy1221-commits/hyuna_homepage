# 김현아 — 일상의 취향

프로야구 관람(LG 트윈스), 커피 창업에 대한 관심, 고양이를 좋아하는 김현아의 개인 홈페이지입니다.

## 배포

- 공개 Site: https://hyuna-kim-home.lastshell4.chatgpt.site/
- GitHub Pages: `.github/workflows/deploy-pages.yml`이 `main`에 변경이 들어오면 `dist/` 내용을 배포합니다.

## 파일

- `dist/index.html`: 정적 홈페이지
- `dist/hyuna-kim.png`: 메인 사진
- `.openai/hosting.json`: Sites 호스팅 설정
